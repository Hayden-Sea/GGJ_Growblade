## 游戏介绍

《剑会变长》是一款 2D 俯视角同步回合制解谜游戏。玩家通过果实让剑从任意节点继续生长，并在有限空间中控制剑的形状。剑身可以攻击和击退敌人、推动箱子，也会被墙壁阻挡。玩家需要在每一拍中选择移动、转剑或等待，完成 12 个逐步组合规则的短关卡。

## GameJam 发布内容

- 12 个可游玩关卡，通关后依次解锁并保存进度。
- 自由节点生长、折角与分叉剑形。
- 移动和旋转时的连续碰撞、命中、击退与回弹。
- 冲锋怪绕剑追击，弩手按预备、射击、冷却三拍行动。
- 普通果和数字多生长果。
- 可推动箱子、压力机关、出口和核心目标。
- 首关教程、暂停菜单、音乐与音效音量控制、胜负结算和关卡选择。
- 关卡编辑器支持尺寸、目标文本、生命、玩家与剑朝向、敌人、果实、箱子、机关、核心和出口编辑。

## 操作

| 输入 | 行为 |
| --- | --- |
| W/A/S/D 或方向键 | 移动 |
| Q / E | 逆时针 / 顺时针转剑 90° |
| Space | 等待并经过一拍 |
| 鼠标左键 | 生长阶段确认剑节 |
| Esc | 暂停 |
