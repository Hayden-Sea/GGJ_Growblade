## 必须完成的三项修改

1. **左键确认。** Growing 中鼠标悬停合法候选后，点击鼠标左键开始长出。Space / Enter 不再确认；战斗 AwaitInput 中 Space 仍只表示等待。
2. **世界内预览与伸长攻击。** 不弹成长窗口；主相机和房间画面不变，在真实剑的候选位置画虚线与高亮。点击后新节从锚点向新端点伸长，途中碰怪按正常剑攻击伤害、击退、撞墙附伤和打断。位置非法不可点击。
3. **解除全局上限。** 每果仍只提供一点、每点仍新增固定 0.5 格。删除运行时 / 编辑器 / 配置中的 5 果、5 次、7 边限制，由作者放置的果数决定本关预算；不是把上限改成 99。

## 关键规则

- 剑砍果和身体拾果均须完整回弹到动作起点；完全归位之后才进入 Growing。
- Growing 冻结本拍敌人；生长不计新拍。成长伤害打断的普通敌人取消该拍意图，其他敌人在所有成长结束 / 暂存后各执行原意图一次。
- GrowthPlacement 保留图规则、墙 / 世界边界、玩家和未收集果检测。敌人 / 核心不再否决候选，改成命中预览目标。
- 新短节从原始 anchor→newNode 的方向生长，不能用规范化排序后的端点反推方向。普通敌人受 1 伤，沿该世界四向方向击退 1 格，复用 CombatRules。
- 只检查新增边首次覆盖的区域。按本文默认，成长开始时已经碰旧剑的目标不由本根攻击，避免进度 0 重复伤害。
- 每根成长每目标一次，使用独立 growthActionId；不要按整个 beatId 去重而吞掉后续成长攻击。
- 核心可被成长攻击，但不击退 / 打断。本根击毁核心时，完成本根及命中表现后通关，取消剩余成长点和敌人响应。出程击毁核心同时取果的旧时序见主文档第 10.4 节。
- 增长不取果，候选接触未收集果仍非法。长完后剑不持续伤害，敌人被堵住未退开也不取消已确认的增长。
- 无合法候选时保留暂存兜底，用 HUD 文案 / 按钮表达，不出现独立剑预览窗口。
- 本关账本：已消费果数 = growthCount + growthCredits，edges.Count = 2 + growthCount。初始两边为 0.5 格与 0.3 格；每一根新边固定为 0.5 格。每次换关 / 重试仍恢复最短剑。

## 输入和画面

替换 GrowthPreview 的隔离舞台、PreviewCamera、RenderTexture、RawImage 与 GrowthPanel。可改造原类或新建 WorldGrowthPreview，世界候选使用主相机与实际玩家格位 / 朝向。

鼠标映射到棋盘平面后转到剑局部；保留吸附、结点死区、旧剑排除和稳定候选排序。初始不得默认选第一个候选。指针移走、遮挡、失焦、暂停时清空。

Growing 只接收新的左键按下；进入 / 连续下一根需先观察到鼠标松开。HUD 点击不可穿透，确认后不能再触发屏幕行动按钮。成长中禁用战斗按钮及 WASD/Q/E/Space/Enter，但保留暂停与无位置暂存。注意全屏 HUD 背景不能把所有地图指针都标成“在 UI 上”。

点击锁定并纯模拟一根 GrowthSimulation，产生 nextState 与按 g 排序的命中事件。表现层将新增边从零长度长到 0.5 格，接触帧播放伤害和击退；等待最后一个击退结束后提交一次工作结果，再继续成长或恢复敌人阶段。预览与正式执行用同一求解器。
