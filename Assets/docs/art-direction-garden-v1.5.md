## 美术资产与接入
- 原创透明图集：`Assets/_Game/Art/Garden/Resources/DoodleAtlas.png`，1774 × 887，八个独立 Sprite。
- 名称依次为 Knight、Charger、Archer、Core、Fruit、Portal、Grass、Flower。双线性采样、无压缩、中心轴点。
- `GardenArtSetup` 提供菜单 Tools → 剑会变长 → Apply Garden Art；自动按图集透明边界裁出八个 Sprite，复用已有 Sprite ID，更新 GameConfig 表现引用。
- 首次应用前配置备份在 `Assets/_Game/Art/Garden/CFG_PreGarden.asset`，旧像素素材保留。
- `GardenTheme` 管理色板、卡片、地砖、爱心和指示箭头。地形与 UI 为代码绘制的基础图形，角色插画通过内置 imagegen 生成。
- 中文字体沿用项目已有 NotoSansSC；图集只承载插画，文字由 TMP 实时绘制。

## 开发注意事项
- `HUDController` 在运行时构建菜单；不要仅修改场景中的临时 UI。按钮回调与音量设置继续走原有逻辑。
- 音量轨道和填充使用 Sliced Image，关闭 preserveAspect；填充 RectTransform 的 offsetMin/offsetMax 必须为零，由 Slider 驱动横向锚点。根物体提供透明点击区域。不要恢复普通保比例图片。
- `RoomView` 自动给任何 RoomDefinition 应用地形和装饰，无需为新关卡重复指定贴图。旧 floor/wall Sprite 引用不再决定棋盘样式。
- `GardenBoardFraming` 自动适配房间尺寸和相机宽高比，在棋盘两侧给 HUD 留空间。
- 剑用统一宽度的浅色线条与墨绿描边。全部剑节使用稳定排序层，避免长剑新增节段落到地面后方。
- 果、敌人和主角只调整视觉外观；逻辑格子、剑边图、成长长度、伤害和击退规则仍以 v1.4 为准。
- 生长提示不拦截鼠标，候选仍在世界中预览；成长确认仍为左键。
- 选关每页九张卡片，可翻页；作者继续使用现有关卡编辑器增删和排序房间。
