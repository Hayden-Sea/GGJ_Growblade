## 任务

请在**现有工程**上继续开发《剑会变长》，目标引擎保持团结 1.10.0（2022.3.62t12），保留现有 URP、资源、场景与 GUID。当前 Demo 基于 1.0，仍有 bug；先复现和记录当前问题，不重建项目。场景是 `Assets/_Game/Scenes/Game.scene`。

完成以下结果：

1. 落实 1.1 的火柴式自由生长：初始两条半格边 `(1,0)–(2,0)`、`(2,0)–(3,0)`；每次可从任意已有结点正交增加一根 0.5 格短节，单关最多增加 5 根。渲染、碰撞与验证共用边图。
2. 落实 1.2：鼠标悬停候选位置显示原位半透明短节，Space 确认；不再 Q/E 切选和 Enter 提交。无候选不可确认，确认键不可透传成战斗等待。
3. 房间有果：身体合法到达果格后打开成长；剑在出程中首次砍到果，先截断并回弹到动作起点，再打开成长。旋转回原朝向；平移砍果则人与剑整体回出发格。
4. 果触发动作仍只耗 1 拍。生长不额外耗拍，本拍敌人等生长结束 / 暂存后执行原意图一次。果之前已发生的伤害、击退和打断保留；回程无伤害、无二次取果。
5. 每关独立：所有开始 / 下一关 / 重试 / 选择 / 调试 / 编辑器试玩入口都创建初始短剑、HP4、0 拍、完整果和敌人。出口不再开成长；确认成长不换关。多房间联通以后再做。
6. 做出第 19 节的可视化关卡编辑器，使关卡作者可自行画图、放敌人与果、新建 / 复制、撤销 / 重做、保存、校验、试玩和排序。至少用工具完成 3 个可通关独立关，时间允许扩为 6 个。

## 不得遗漏的时序与边界

- 完整平移路径撞墙仍整次无效，0 拍 / 0 伤 / 0 果，即使墙前有果。
- 旋转比较墙与果的首次接触，误差内墙优先；多个果只选最早一个，平局按稳定 fruitId。
- 敌人必须严格早于截断点才受击；回弹不能继续扫到果后的目标。
- 成长依据**实际归位后的房间位置**过滤新增节，不能长进墙、玩家、敌人或其他果；也不能通过新节再攻击或取果。
- 无可放置候选时仍开成长，显示“暂存并继续”；保留成长点，之后有效行动到有位置时再开成长。有候选时不能主动跳过；果数 = 成长次数 + 暂存点。
- 已在本动作击毁核心又触果时，先完成果 / 成长，再通关，不执行敌人响应。
- 暂停恢复准确阶段，重试递增 sessionId 并取消旧 PendingBeat / 动画回调。
- 当前可放下新节不能证明后续可通关；不要伪造“全形状安全”结果，使用编辑器检查和参考通关记录。

这些补充默认值已在主文档第 1.2 节标明。如实施中调整规则，先在文档前部新增修改履历并同步对应验收条目，不悄悄改语义。

## 编辑器的最小交付

- 菜单 `Tools/剑会变长/Level Editor`，EditorWindow + IMGUI，使用现有 SwordGame.Editor 程序集。
- RoomDefinition 为唯一数据源；主场景负责显示，不建立第二套 Tilemap / JSON。
- 墙、地面、主出生与朝向、两种敌人、果、出口 / 核心工具，缩放 / 拖动，非法格提示。
- 一笔画墙为一个 Undo；新建 / 复制不覆盖旧文件；复制有新 GUID 和 roomId。
- 保存指定资产；改尺寸先显示越界影响；丢弃修改要实际恢复数据。
- 快速校验硬错误阻止试玩，设计警告允许试玩；问题可点击定位。
- 一键试玩所选关，Domain Reload 后启动参数仍在；不改 RUN_Default、不污染资产；停止后恢复原场景与画布。
- 关卡列表支持上下排序；Play 期间不允许工具修改共享资产；Windows 构建不依赖 UnityEditor。
- 完成主文档第 19.7 节的作者流程与 E01–E13 验收。编辑器的高级框选和完整解谜求解器可后做。
