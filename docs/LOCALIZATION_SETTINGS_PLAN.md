# Growblade 多语言与设置体验规划

> 实施状态：已于 v1.13.0 完成并验收。

## 第二阶段：日语、韩语与可扩展架构

- 支持语言扩展为 English、简体中文、日本語、한국어，默认值与既有存档编号保持兼容。
- 设置页默认只显示一个当前语言选择框；点击后由语言目录自动生成下拉列表，不再为每种语言声明独立按钮字段。
- 每种语言由一份 `LanguageDefinition` 描述：稳定枚举值、本地语言名、静态词表和关卡目标。
- 关卡名称不翻译，始终直接显示关卡编辑器 `roomId` 中对应的英文文本。
- 动态数字文本由本地化层统一格式化，业务代码不再判断具体语言。
- 后续新增语言只需增加枚举值、语言定义和词表；设置 UI、选中态和持久化逻辑无需修改。

## 目标

- 运行时界面支持 English、简体中文、日本語与한국어，首次启动默认 English。
- 标题页在 Play 与 Quit 之间增加 Settings，保持三个按钮同宽、清晰分级。
- 音乐、音效、镜头震动和语言集中到同一个 Settings 面板。
- 标题页与暂停页都能进入同一设置界面；关闭后回到进入前的界面。
- 语言切换立即生效并通过 PlayerPrefs 持久化，不要求重启或重新进关。

## 交互设计

### 标题页

主按钮 Play 保持金色和较高视觉权重；Settings 与 Quit 使用浅色次级按钮，三者垂直排列。略微压缩按钮间距，维持现有左侧文字、右侧插画的留白和平衡。

### 设置面板

设置使用居中的纸张卡片，包含：

1. Language：单一选择框显示当前语言；点击展开下拉列表，语言始终使用自己的名称，选中后立即应用并收起。视口最多显示 4 行，更多语言通过滚轮或滚动条浏览，设置面板高度不随语言数量增加。
2. Music：即时生效的滑杆。
3. Sound Effects：即时生效的滑杆。
4. Screen Shake：开关。
5. Back：返回标题或暂停页。

暂停页不再直接堆叠音量控件，而增加 Settings 入口。这样标题和游戏中使用同一份设置，减少重复控件及行为差异。

## 技术方案

- `GameLocalization` 维护可枚举的语言目录；当前支持 English / SimplifiedChinese / Japanese / Korean。
- 使用 `growblade_language` 保存选择；键不存在时返回 English。
- 代码生成 UI 的静态文本在创建时登记原文，切换语言后统一刷新。
- 动态 HUD、提示、结算统计使用专门格式化函数；关卡目标按稳定 `roomId` 映射，不修改现有关卡资产 schema。
- 内部日志、对象名和关卡编辑器不本地化，它们不是玩家界面。
- 韩文使用随项目发布的 Noto Sans KR 动态字体资产，并永久注册为主 UI 字体的 fallback。这样无论当前语言是什么，下拉列表中的 `한국어` 和任何混排韩文都不会出现缺字方框。

## 文本范围

- 标题、选关、HUD、成长提示、暂停、设置、教程、确认框和结算。
- 游戏中行动无效、目标完成、成长和教程提示。
- 12 关目标说明；关卡名称固定使用编辑器英文文本。

## 验收标准

- 清空语言存档后进入游戏，标题页首先显示 English。
- 标题页 Play / Settings / Quit 排列整洁且 Settings 可打开面板。
- 从标题进入设置后 Back 返回标题；从暂停进入设置后 Back 返回暂停。
- 切换语言时当前画面即时刷新，重启后保留选择。
- 两种语言下按钮和主要文本不截断，玩法与输入行为不受影响。
- 本地化规则测试、现有 EditMode 测试和房间校验通过。

## 多语言排版约束

- 运行时文本不得使用 Ellipsis 作为默认溢出策略；文本应先自动缩小和换行，并保留可见溢出供 QA 发现。
- 紧凑方形按钮使用更小字号和较窄内边距，保证 WAIT 等四字符动作完整显示。
- 设置滑杆标签预留 130px，不按中文两字宽度设计。
- 新增语言时需检查标题、设置、选关、HUD、教程、暂停及结算七类界面；不可通过缩短含义来掩盖布局问题。
