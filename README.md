# 剑会变长

> 2D 俯视回合制地牢：每关拿起短剑，在房内碰到或砍到「果」获得成长；用越来越难转身的剑完成一拍一动的战斗，再以短剑挑战下一关。
>
> 团结引擎 1.10.0（2022.3.62t12）· URP · v1.4 已实现

## 运行

1. 用团结引擎 1.10.0 打开本工程。
2. 打开 `Assets/_Game/Scenes/Game.scene` 并运行。
3. 标题 → 关卡选择；新存档仅开放第 1 关，通关后依序解锁下一关，也可在选关页确认解锁全部。

## 操作

| 按键 | 行为 | 耗拍 |
| --- | --- | --- |
| W/A/S/D 或方向键 | 人与剑整体尝试平移 1 格；撞墙时前探回弹并消耗一拍，不拾取墙前果 | 输入阶段 |
| Q / E | 剑逆/顺时针转 90°（撞墙 / 砍果均截断回弹、保持朝向） | 总是 |
| Space | 战斗中=等待（成长界面不再确认） | 战斗中 1 |
| Esc | 暂停（精确恢复原阶段；重试本关 / 选择关卡） | 0 |
| 鼠标 | 成长中在战斗画面悬停候选短节，左键确认生长（非法位置不可选） | 0 |

屏幕右下角有可点击的行动按钮。

## 一关流程

短剑开局（0.5 格根段 + 0.3 格尖段，触及 1.3 格）→ 身体碰果或剑砍果（剑砍果截断回弹）→ 战斗画面世界内悬停候选、左键长出新节（每节 0.5 格，伸长途中命中敌人造成伤害 / 击退 / 打断）→ 同一拍敌人原意图继续响应 → 依关卡目标进入出口 → 下一关重新短剑开局。果数 = 本关成长预算，无全局上限。

## 关卡编辑器

菜单 `Tools/剑会变长/Level Editor`：

1. 「新建」→ 画笔画墙 / 柱，放主出生点与朝向（画布可见初始剑轮廓）。
2. 放任意数量的果（果数 = 本关成长预算，无上限；工具栏显示当前数量）、敌人和出口（或切 DestroyCore 放核心）。
3. 「校验」处理红色硬错误（黄色为设计警告）。
4. 「保存并试玩本关」→ 自动打开 Game.scene 从该关短剑开局；停止后自动恢复原编辑场景。
5. 「复制」衍生新关；列表 ↑/↓ 调整「下一关」顺序。
